# hello-world-pages

GitHub Pages を使った **公開テスト・動作確認用リポジトリ** です。

## Purpose

- 開発途中のHTML / JavaScript / WebGPU / Audioなどを外部ブラウザで確認する
- GitHub Pages上での挙動、モバイル表示、音声、権限、ブラウザ差などを試す
- 一時的なデモや検証版を公開する
- 完成前の成果物を気軽に置いて実機確認する

このリポジトリの内容は、**常に安定版・完成版であることを保証しません**。
途中経過や壊れた検証版が置かれることがあります。

## Public test site

https://2rwa.github.io/hello-world-pages/

## Stable public site

動作確認が完了した完成版・安定版は、原則として以下へ移します。

- Repository: https://github.com/2rwa/2rwa-public
- Pages: https://2rwa.github.io/2rwa-public/

## Policy

`hello-world-pages` = 公開テスト / 実機確認 / 一時デモ  
`2rwa-public` = 動作確認済みの公開成果物
