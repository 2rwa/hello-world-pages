# FFT Ocean V3 — Spray & Wake

V1/V2を変更しない独立WebGPU版。5帯域GPU FFT、球体の27点GPU波高浮力、
ワールド固定2段の泡履歴、プロシージャル空・吸収/後方散乱をV2から継承。

## V3の主な変更点

- **GPUしぶき粒子**: 1024粒子（CI）、1536粒子（軽量）、3072粒子（高画質）。
  Compute shaderで位置/速度/年齢/寿命/粒径を保持し、重力、風、粒径に依存した抵抗で移動。
  ボール前方の航跡発生点から排出。波と球体の相対上下速度でスラミング強度を推定。
  GPU側で決定的な粒子シードを保存。フラグメントで2ローブHG近似散乱。
- **描画**: 粒子はカメラ向きクアッド。遠景で見かけの直径が1.5px未満の場合、
  最小描画サイズを保ちながら粒の面積分だけアルファを下げてちらつきを緩和。
  屈折させず半透明合成。計算computeと読み取りvertexのレイアウトは分離。
- **航跡**: 白泡の細い周期的なレース模様を波速・横位置・シードで変調。
  泡履歴の4チャネル（被覆、鮮度、気泡、スリック）は維持。
- **UI**: しぶきの量、航跡の泡レースを追加。従来のFFT品質、風速、波高倍率、
  太陽高度、濁り、カメラ、デバッグ表示も継続。
- **回帰テスト**: GitHub ActionsのSwiftShaderでGPUコンパイル、FFT/泡/粒子
  compute、海面/球体/粒子のdraw、GPUの粒子状態と画面readbackまでチェック。
