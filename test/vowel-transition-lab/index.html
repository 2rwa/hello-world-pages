線は二次 Bézier 曲線です。中間点は「実際に別の母音を発音している」という意味ではなく、調音器官が移動する途中のスペクトル形状を操作するための制御点です。

何を聴いているか

F1
概ね舌の高さ・口の開きに対応。高いほど開いた母音寄り。

F2
概ね舌の前後位置に対応。高いほど前舌母音寄り。

軌跡
開始と終了が同じでも、途中でどこを通るか・何秒かけるかで聞こえ方が変わります。

音源は Web Audio API の鋸歯状波を F1/F2/F3 の帯域通過フィルタへ並列に通す簡易フォルマント合成です。自然音声そのものではなく、母音色の連続変化を観察するためのモデルです。
