# ぐつぐつ戦線 — 軽量RTSプロトタイプ

NotebookLM Deep Researchで整理した「低APMの国取り / 短い自動戦闘 / 一発逆転の切り札 / 弱小将軍にも用途」という設計仮説を、最小規模で検証するブラウザ試作。

## 今回検証する核

1. 将軍の駒を拠点へドラッグするだけでも国取りの判断が成立するか。
2. 20〜40秒程度の自動戦闘に、1〜3秒の長押し召喚を挟むだけで緊張と逆転感が出るか。
3. 俊足だが弱い将軍を、資源確保や時間稼ぎに使いたくなるか。
4. 召喚を完全ランダムにせず、材料2種＋煮込み段階で予測可能にすると試行錯誤が楽しいか。

## 仕様

- 6拠点
- 味方3将軍 / 敵3将軍
- 材料3種: 若菜・火種・雷粉
- 材料の重複を含む6組 × 浅炊き/適温/焦げ = 18結果
- 拠点を取ると3秒ごとに対応素材を産出
- 敵AIは非敵拠点へ単純侵攻
- 撃破された将軍は短いクールダウン後に本拠地から復帰
- 180秒で沸点100%。敵の白兵戦ダメージが徐々に上がる

## 操作

- マップ上の青い将軍駒をドラッグして拠点へ移動
- 右側カードで材料2つを仕込む
- 戦闘中、鍋ボタンを長押しして離す
  - 0.85秒未満: 浅炊き
  - 0.85〜約2.15秒: 適温
  - それ以上: 焦げ
- 料理値が高い将軍は適温判定が少し広い
- 撤退すると直前の拠点へ戻る

## 構成

Vanilla HTML / CSS / Canvas 2D / ES Modules。外部依存なし。

`?ci=1` で、仕込みUI→状態反映、戦闘表示、召喚ダメージ、移動進行の回帰チェックを実行し、`html[data-ci-status="ok"]` を設定する。
