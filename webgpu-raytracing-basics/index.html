01 / PRIMARY RAY

各画素をGPUのスレッドに

8×8スレッドを1ワークグループとして起動し、球2個と床との交差を計算。最短の正の距離から法線と色を求めます。

02 / SECONDARY RAYS

影と反射もレイで調べる

「影」をONにすると光源方向への遮蔽検査を追加。反射回数を増やすと反射方向に次のレイを飛ばします。

03 / GPU PIPELINE

計算と画面表示は別

Compute Shaderで rgba8unorm のGPUテクスチャに書き込み、画面表示は専用の頂点・フラグメントシェーダーに渡します。

レイトレーシングの種類に注意

この教材はCompute Shaderによるソフトウェア交差判定です。専用のハードウェアRTパイプラインやBVHを使う実装ではありません。また確率的なパストレーシングでもなく、球と平面に限った鏡面反射の練習用実装です。
