# WebGPU ray tracing basics — public preview

This folder is an isolated public-test copy of chapter 6 from [2rwa/tmp-3d](https://github.com/2rwa/tmp-3d).

- Interactive preview: [index.html](index.html)
- Canonical lesson: https://tmp-3d.pages.dev/chapters/06-webgpu-raytracing/textbook.html
- Canonical demo: https://tmp-3d.pages.dev/chapters/06-webgpu-raytracing/

It uses WebGPU compute shaders to intersect two spheres and a plane, with shadows and up to three reflection bounces. No hardware ray-tracing acceleration structures are used.

Preview assets are copied from the validated chapter. The shared stylesheet is copied locally, and navigation links point back to the canonical lesson. Please make changes in the source repository first.
