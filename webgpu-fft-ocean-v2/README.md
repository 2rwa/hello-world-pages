# FFT Ocean V2 — WebGPU

V1とは別ディレクトリの海面シミュレーション実験。V1の5段GPU FFTを保ったまま
画質・浮体・泡シミュレーションを改善したバージョンです。

## 新規/変更した機能
- **海面**: 5段JONSWAP系FFTの波高・変位・スロープモーメントMIPを維持。
  遠景のサブピクセル法線と反射のエイリアシングを低減。
- **空と反射**: カメラ追従のプロシージャル空、時刻によって変わる太陽高度、
  雲・空の水面反射、雲影。実HDRIではありません。
- **水の色**: 吸収係数と後方散乱の比から算出。濁りを数値変更可能。
- **泡**: 420m/3.2km の2段ワールド空間履歴、風と渦による再投影移流、
  4チャネル（被覆/鮮度/気泡/スリック）、ヤコビアンによる白波検出。
  航跡はケルビン角19.47°を使ったV字と周期波を含む。
  細い泡模様はプロシージャル生成で写真テクスチャは未使用。
- **球体**: 27点のGPU波高を非同期リードバックし、上下移動に加え
  前後左右の差分で推定したロールとピッチを反映。
- **操作**: 風速、振幅、泡量、速度、太陽高度、濁り、3種のカメラ、
  法線/泡/粗さのデバッグ切替、一時停止、航跡消去。
- **回帰検証**: GitHub ActionsのSwiftShader上で 128², 512²、
  泡デバッグと低太陽高度を実描画・GPU readback。
  非CI表示ではWebGPU canvas、CIは同じshader/pipelineをオフスクリーンに描画。

## 未実装・制限
- LEADR完全実装、HDRI太陽光実測、真の平面反射、ボリュメトリッククラウド、
  実写真テクスチャ、独立した2系統の航跡RT、GPUしぶきパーティクル、
  27点浮力の剛体運動積分、定量的Monahan被覆率、駆逐艦モデル。
- 改善した画質は手続き的な近似。物理校正済みの海面再現ではありません。
- 512² × 5は端末によってかなり重いため、128²軽量モードも用意。
