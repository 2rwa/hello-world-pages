# Pelagic Amoeba — SDF Glass Runner

FFT Ocean V3 を変更せずに派生させた独立 WebGPU 実験です。
海面を疾走する、透明なガラス／ゲル状のSDFメタボール生命体。

## 操作
- SDF球数: **3 (初期値) ～ 100**
- smooth union融合幅、脈動、走行時の伸長
- ガラス屈折率 1.01〜2.4、吸収、発光、合成の強さ
- 内部反射バウンス **0〜3**、レイマーチの上限 **24〜96** ステップ
- 海面FFT品質、風速、波高、速度、カメラ、航跡、飛沫

## 描画
1. V3由来の5カスケードGPU FFT、泡履歴、飛沫compute、波高27点サンプル
2. オフスクリーンへ空／海面／飛沫をラスタライズし、深度も保存
3. フルスクリーン合成で解析的境界球を先に判定し、命中する画素だけSDFを評価
4. smooth unionの符号付き距離を安全係数付きSphere Tracingで探索
5. 入射／内部／出射、フレネル、内部反射の上限、Beer–Lambert吸収
6. 背景テクスチャをスクリーンスペース屈折でサンプル。海より後ろの部分は深度で隠す

**制限:** 屈折先は画面空間近似で、物理的なFFT波面との再交差は行わない。
波面の透過、海面へのアメーバの正確な反射、アメーバ形状に応じた浮力積分は未実装。
内部反射は逐次経路の近似で、分岐する全経路を追跡しない。
100球と3バウンスでは処理負荷が高い（最初は3球を推奨）。
